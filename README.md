# One Set To Failure

Public marketing site for **One Set To Failure** — a minimalist high-intensity strength training log for iOS and Android.

**Live site:** [https://onesettofailure.app](https://onesettofailure.app)

## About

One Set To Failure is built around HIT-style training: one top set taken to true failure, recovery-aware exercise selection, location-based equipment, plate math, and progress charts.

## Project structure

```
index.html      Landing page
css/main.css    Styles
js/main.js      Lightbox and UI behavior
screenshots/    App screenshots
```

## Local development

This is a static site with no build step. Serve the project root with any static file server, for example:

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).
